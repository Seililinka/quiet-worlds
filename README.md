# Тихие миры

Три живых мира — лес, замок и город. Обитатели выбирают занятия, а звуки и музыка создаются в браузере в реальном времени. Можно менять время суток, погоду и громкость отдельных слоёв.

Дождь в лесу и городе воспроизводит целиком исходный 15-секундный звук, который одобрила автор проекта (`assets/forest-rain-v13.mp3`, Runway Sound Effects). Файл сохранён без редактирования, нарезки, смены скорости и панорамы. На стыке повторений — плавное секундное перекрытие. Громкость зависит от погоды и настроек воды и природы. Пока файл загружается, дождь молчит; при ошибке появляется сообщение с предложением повторить загрузку. Море, водопад и дождь по крыше замка используют прежний синтез. В городе погода видна на всей сцене: капли, лужицы и отражения фонарей; при уменьшенной анимации погода остаётся видимой без движения. Замок стоит на берегу океана, лес сохранён слева. Атмосфера «Океан у стен» включает мягкий прибой и арфу.

## Публикация на GitHub Pages

Файлы этой папки размещаются в корне репозитория. Сборка и сервер приложения не требуются.

В репозитории откройте Settings → Pages → Deploy from a branch. Выберите ветку main и папку / (root), затем Save. GitHub покажет адрес сайта после публикации.

## Запуск

Откройте опубликованный HTTPS-адрес и нажмите «Слушать». Для локального просмотра запустите из этой папки `python3 -m http.server 8000` и откройте http://localhost:8000.

Лес: index.html. Замок: castle.html. Город: city.html. Изображения: assets/. Звуковой движок: forest-processor.js.

Настройки хранятся в браузере отдельно для каждого адреса сайта. На новом адресе сохранённые настройки старого сайта автоматически не появятся.

Встроен счётчик Яндекс.Метрики 113103435 с событием radio_start. Для работы миров не требуются ключи API или аккаунт ChatGPT.

Самостоятельный эксперимент по мотивам Murmur (https://www.murmur.living/), с собственными изображениями, логикой и процедурным звуком.

Инструкция GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
